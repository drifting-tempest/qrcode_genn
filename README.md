# QR CODE GENERATOR

A QR Code Generator that lets the user generate a QR Code and also lets them choose its colors, as well as suggests for the same.

## Design Aspect

1. Neobrutalism UI
2. Confetti Effect after generating the QR Code
3. Vertical overflow of elements + objects that appear after user interaction

Link (Live Demo): https://drifting-tempest.github.io/qrcode_genn/
